# Հայերեն Python — Android ուսուցման հավելված

Անվան առաջարկվող GitHub repository-ն՝ **`hay-python-android`**։ Այս նախագծում 16 դաս կա՝ Python-ի առաջին հրամանից մինչև JSON և API-ների հիմունքներ։ Յուրաքանչյուր դասի վերջում կան երկու ստուգողական հարց։ Սխալ պատասխանի դեպքում հավելվածը բացատրում է թեման, թույլ է տալիս նորից փորձել և հաջորդ հարցը/դասը չի բացում, մինչև ճիշտ չպատասխանես։ Բացված դասերի առաջընթացը պահվում է սարքում։

Հավելվածի միջերեսը և բացատրությունները հայերեն են։ Python-ի կոդային բառերը մնում են անգլերեն, ինչպես ընդունված է լեզվում։ Միջերեսը հարմարեցված է փոքր և մեծ էկրաններին՝ հեռախոսում դասերի հորիզոնական ընտրությամբ, լայն էկրաններին՝ կողային դասացանկով։ Android-ի լայն սարքային համատեղելիության համար սահմանված է minSdk 23։

> «Աշխարհի լավագույնը» դառնալը որևէ հավելված չի կարող երաշխավորել․ դրա համար պետք են երկարատև պրակտիկա, իրական նախագծեր, code review և համայնքի հետ աշխատանք։ Այս հավելվածը տալիս է ուսուցման մեկնարկային ուղի, ոչ թե ավարտուն համաշխարհային մակարդակի դասագիրք։ Ավելի առաջ գնալու համար ավելացրու նախագծեր, Git, SQL, տվյալների կառուցվածքներ, ալգորիթմներ, վեբ/API մշակում, անվտանգություն, async, տեղակայում և բաց կոդով ներդրումներ։

## GitHub-ում տեղադրելու և կառուցելու քայլերը

1. GitHub-ում ստեղծիր նոր դատարկ repository՝ **`hay-python-android`** անունով։
2. ZIP-ը բացիր repository-ի արմատային պանակում և commit արա ներսի ամբողջ բովանդակությունը (ոչ թե միայն workflow-ն)։ Պետք է repository-ի արմատում երևան `app/`, `build.gradle.kts`, `settings.gradle.kts` և `.github/workflows/android-ci.yml`։
3. Փոփոխությունները commit արա `main` branch։ GitHub Actions-ը ինքնաբերաբար գործարկի **Build Android APK** workflow-ը։ Կարող ես նաև ձեռքով սկսել՝ **Actions → Build Android APK → Run workflow**։
4. Երբ workflow-ն հաջողությամբ ավարտվի, բացիր դրա run-ը, ներքևում գտիր **Artifacts** և ներբեռնիր `hay-python-debug-apk`։ ZIP արխիվի ներսում կլինի `app-debug.apk`։
5. APK-ն սարքում տեղադրելու համար պատճենիր այն Android հեռախոս կամ պլանշետ և թույլատրի՛ր այդ աղբյուրից հավելվածների տեղադրումը։ Debug APK-ն փորձարկման համար է․ հրապարակային Play Store-ի համար պետք է ստեղծել ստորագրված release build։

### Workflow-ի կոդը

Ամբողջ workflow-ն արդեն ավելացված է `.github/workflows/android-ci.yml` ֆայլում։ Այն օգտագործում է վավեր Android SDK փաթեթները (`platform-tools`, `platforms;android-35`, `build-tools;35.0.0`)՝ հին և բացակայող `tools` փաթեթի փոխարեն։ GitHub Actions-ի էական build հրամանը՝

```yaml
- name: Build debug APK
  run: gradle --no-daemon :app:assembleDebug
```

Ամբողջ workflow-ն ապահովում է Java 17-ը և Android SDK-ն, կառուցում է APK-ն և պահում այն որպես ներբեռնվող artifact։

## Տեղային կառուցում

Պահանջվում են JDK 17, Android SDK (API 35) և Gradle 8.9։ Android Studio-ում բացիր նախագիծը և ընտրիր **Build → Build Bundle(s) / APK(s) → Build APK(s)**։ Կամ տերմինալում՝

```bash
gradle assembleDebug
```

APK-ի տեղը՝ `app/build/outputs/apk/debug/app-debug.apk`։

## Բովանդակություն

Դասերը հերթով ծածկում են՝ առաջին հրամաններ, փոփոխականներ և տեսակներ, input/փոխակերպում, օպերատորներ, պայմաններ, ցիկլեր, տողեր, list/set, բառարաններ, ֆունկցիաներ, մոդուլներ/venv, բացառություններ, ֆայլեր, դասեր/օբյեկտներ, թեստավորում/վրիպազերծում, JSON/API-ներ։ Յուրաքանչյուր դաս ունի օրինակի կոդ, հիմնական միտք, և երկու հայերեն վիկտորինայի հարց՝ պատասխանների բացատրություններով։
